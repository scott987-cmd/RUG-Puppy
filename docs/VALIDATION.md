## 文件与发布范围

源码包中共有 651 个条目（648 个文件、3 个指向包内的相对符号链接）。`release/FILES.tsv` 记录每个条目的路径、大小、类型和 SHA-256。已逐条从压缩包重新读取并与清单校验。归档只含源码目录，编译镜像和本地验证日志放在独立的 `verification/` 目录。

家庭证据目录、录音、照片、手机 QA 截图、配对文件、生产配置与密钥、历史 Git 对象和构建缓存均已排除。逐文件扫描未找到已知家庭设备标识、原主机名、个人绝对路径、常见格式的 API 密钥或私钥头。测试使用合成夹具。固件保留 142 个上游动画、提示音和唤醒资源，与公开的 `eb81c22` 基准逐字节一致。外部 MLX 权重由使用者自行获取。iOS 使用系统默认图标。

候选沿用上游声明的 Apache-2.0，根目录补入许可证正文和 `NOTICE`，保留第三方组件原署名。上游改动文件附修改说明。固件和网关示例默认启用安静陪玩，设备令牌留空，网关使用可替换的通用主机名。

候选内修正了两处 Python 测试夹具。公共问答补上实际流程会调用的答案复核模拟，音频测试用 WebSocket 正常断开事件收尾；两项调整均在测试文件中。

这轮验收覆盖源码包、构建、宿主机和模拟器。候选尚未刷入小狗或安装到实体手机。儿童独立使用、不同光照识物、带动作的低声急停以及声音定位仍待实机验收。
